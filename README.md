# Already Solved – Solution Repository

This repository stores reconstructed levels for the puzzle game [Already Solved](https://blasterpoard.itch.io/already-solved).

In the game, you are given a solution path. Your task is to rebuild the level so that this path is the **unique shortest solution**. Any unintended shorter solution will be rejected.

This repository aims to collect reconstructed levels for all 70 solutions provided by the game. It is currently a work in progress – not all levels have been completed yet.

# Already Solved – 解法仓库

本仓库存储了解谜游戏 [Already Solved](https://blasterpoard.itch.io/already-solved) 的重建关卡。

游戏中，你会得到一条解法路径。你的任务是重建关卡，使该路径成为**唯一的最短解法**。任何意外的更短解法都会被拒绝。

本仓库旨在收集游戏提供的全部 70 个解法的重建关卡。目前仍在更新中，尚未全部完成。
